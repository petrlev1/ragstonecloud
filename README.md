# Облако

Личный веб-сервис файлов (аналог Google Drive) на FastAPI.
Отдаёт домашний каталог сервера (`/home/mitino12`) через браузер.

## Запуск

    ./run.sh            # первый раз спросит пароль и создаст config.json
                        # (или: CLOUD_PASSWORD=... ./run.sh — без вопросов)

Сервис: http://<хост>:8080  (порт/хост: PORT=..., HOST=...)

## Вход: логин и пароль

Вход — логин + пароль. Логин (ключ `user` в config.json, регистр не важен) и
PBKDF2-хеш пароля лежат в config.json — вне git:

    ./venv/bin/python app/setup.py --user '+79779057956' --password 'новый_пароль'

Без `--user`/`--password` setup.py спросит оба: логин — с текущим значением в
подсказке, пароль — Enter, чтобы оставить прежний.
Нет ключа `user` в config.json — вход по одному паролю (совместимость со старыми конфигами).

## Устройство

- `app/` — FastAPI-приложение (main.py — маршруты, auth.py — логин/пароль и сессии,
  storage.py — безопасный доступ к файлам, config.py — конфиг, setup.py — создание конфига)
- `static/index.html` — интерфейс (один файл, без сборки)
- `config.json` — корень хранилища, секрет сессий, логин и хеш пароля, доступ к БД индекса. Вне git!
- Полнотекстовый поиск — PostgreSQL (БД `cloud`): русская морфология + pg_trgm по именам
- Первичная индексация: ~61 тыс. файлов ≈ 8-10 минут в фоне (лог: /tmp/cloud.log)

## Безопасность

- Пароль хранится только как PBKDF2-хеш, секрет сессий — в config.json (права 600)
- Вход ограничен по скорости (5 попыток/мин с IP)
- Всё ходит строго внутри корня хранилища (проверка реальных путей)
- Сейчас это HTTP — при публичном доступе из интернета завернуть в HTTPS (Caddy)
